Mục tiêu: Script Python tính tổng các số nguyên từ file văn bản và in ra định dạng "TONG=<số>".

Đầu ra:
- sum_integers.py: Script Python xử lý logic.
- input.txt: File mẫu chứa dữ liệu test.

Ràng buộc:
- Bỏ qua các dòng không phải số nguyên.
- Sử dụng thư viện chuẩn của Python.
- In kết quả đúng định dạng "TONG=<số>".

Nằm ngoài phạm vi:
- Xử lý số thực (float).
- Xử lý file cực lớn (không yêu cầu đặc biệt).
- Giao diện người dùng (GUI).

Tiêu chí nghiệm thu:
- Chạy `python sum_integers.py` với `input.txt` chứa `1\n2\n3\nkhông_phải_số` trả về `TONG=6`.
- Chạy với `input.txt` chứa `10\n20` trả về `TONG=30`.
